# "Setting Up Your Daily View Screen" — Social Cut v1

**Purpose:** Condensed version of the full setup video, for social
(Reels / TikTok / Shorts) and embedding on the landing page. Same voice
and UI copy as the full script — just faster.

**Format:** Vertical (9:16), live-action b-roll intercut with screen
recording. Assume mostly-muted autoplay: **burned-in captions are not
optional** for this cut — see companion `.srt` file for exact text/timing.

**Target runtime:** ~1:10–1:20

---

## Scene 1 — Hook (Live-action)

**Visual:** Daily View screen already running on a kitchen counter,
showing today's schedule.

**VO:** "Setting up your Daily View screen takes about a minute."

**On-screen text:** *Setting up your screen*

**Duration:** 0:00–0:06

---

## Scene 2 — Power + Wi-Fi (Live-action, fast cuts)

**Visual:** Quick cuts: plugging in charger, tapping power on, tapping
through Wi-Fi settings.

**VO:** "Plug it in, turn it on, and connect to your Wi-Fi."

**On-screen text:** *1. Power on + connect Wi-Fi*

**Duration:** 0:06–0:16

---

## Scene 3 — Browser, URL, Add to Home Screen (Screen recording)

**Visual:** Fast screen capture: opening a browser, typing the address,
tapping the menu, tapping "Add to Home Screen."

**VO:** "Open a browser, go to [SCREEN URL], and add it to the home
screen."

**On-screen text:** *2. Go to [SCREEN URL] → Add to Home Screen*

**Duration:** 0:16–0:30

---

## Scene 4 — "Connect this screen" (Screen recording)

**Visual:** The pairing screen appears — logo, "Connect this screen,"
empty code box.

**VO:** "It'll ask for a code."

**On-screen text:** *Connect this screen*

**Duration:** 0:30–0:36

## Scene 5 — Get the code (Screen recording, phone)

**Visual:** Quick capture on a phone: dashboard → Devices → Add device →

**VO:** "On your own phone, open your Daily View dashboard, go to

**On-screen text:** *3. On YOUR phone: Devices → Add device*

**Duration:** 0:36–0:55

## Scene 6 — Enter the code (Screen recording, back to tablet)

**Visual:** Typing the code into the tablet's code box, tapping Connect.

**VO:** "Type the code in, and tap Connect."

**On-screen text:** *4. Enter code → Connect*

**Duration:** 0:55–1:03

## Scene 7 — Payoff (Live-action + screen recording)

**Visual:** Screen switches to the live Daily View schedule. Cut to
live-action: the finished screen sitting in place, someone glancing at

**VO:** "That's it — done. It updates itself from here on."

**On-screen text:** *Connected — updates automatically*
End card: *Daily View — [SCREEN URL]*

**Duration:** 1:03–1:15

---

## Production notes

- This cut reuses the exact same on-screen UI moments as the full video —
  film both from the same takes/screen recordings where possible, and
  just re-cut for length rather than re-shooting.
- Keep on-screen step labels (*1. / 2. / 3. / 4.*) visible for at least
  1.5s each — social viewers scrub, and the numbered steps are the
  takeaway if they watch nothing else.
- Same caution as the full script: don't let a real pairing code/QR sit
  on screen long enough to be paused and reused.
