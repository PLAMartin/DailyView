
# "Setting Up Your Daily View Screen" — Video Script v1

**Purpose:** Help a family member/carer install and pair a physical screen
(tablet or display) for the person who will use it as their Daily View
viewer.

**Audience:** The carer/family member doing the setup — not the viewer
themselves. Tone should still follow the site's voice: calm, plain
language, reassuring, no jargon.

**Format:** Live-action (unboxing/placing the tablet) intercut with
screen recording (the pairing steps on the tablet and on the dashboard).

**Target runtime:** ~2:30–3:00

**Before filming — confirm these with the team:**
- The exact web address people type to reach the Daily View screen is 
  `www.dailyview.org/display` (used throughout below).
- Which tablet/device is actually being shipped or recommended, so the
  live-action shots match reality (the spec only says "a supplied tablet
  or display device" — not brand-specific): iPad in landscape

---

## Scene 1 — Cold open (Live-action)

**Visual:** Warm, simple shot of a Daily View screen already running,
sitting on a kitchen counter or side table, showing today's schedule.
A person glances at it calmly.

**VO:**
> "Setting up your Daily View screen takes about five minutes. Here's
> everything you need to do. No technical experience required."

**On-screen text:** *Daily View: Setting up your screen*

**Duration:** 0:00–0:12

---

## Scene 2 — What you'll need (Live-action, tabletop shot)

**Visual:** Flat-lay of: the tablet/screen, its charger, and a phone or
laptop (representing "your own device" for the dashboard).

**VO:**
> "You'll need three things: the screen itself, its charger, and your own
> phone or computer — because you'll set this up from your Daily View
> account, not from the screen."

**On-screen text (as each item appears):**
1. The screen
2. Its charger
3. Your mobile phone or computer

**Duration:** 0:12–0:28

---

## Scene 3 — Power on and connect Wi-Fi (Live-action)

**Visual:** Hands plugging in the tablet, powering it on, connecting to
home Wi-Fi through the device's normal system settings.

**VO:**
> "First, plug in the screen and turn it on. Connect it to your home
> Wi-Fi as you would with any tablet or laptop."

**On-screen text:** *Step 1: Power on and connect to Wi-Fi*

**Duration:** 0:28–0:45

---

## Scene 4 — Open the browser and go to the Daily View address (Screen recording)

**Visual:** Screen capture of the tablet's browser opening, typing the
address bar.

**VO:**
> "Next, open a web browser on the screen and go to
> [www.dailyview.org/display]."

**On-screen text:** *[www.dailyview.org/display]*

**Note:** Type the URL slowly on screen and hold for a beat; carers may
be pausing the video to copy it.

**Duration:** 0:45–0:58

---

## Scene 5 — Add to Home Screen (Screen recording)

**Visual:** Screen capture of the browser's share/menu button, tapping
"Add to Home Screen," and the Daily View icon appearing.

**VO:**
> "While you're there, add it to the home screen. That way, next time the
> screen restarts, Daily View opens automatically — no need to type the
> address again."

**On-screen text:** *Step 2 — Add to Home Screen (do this once)*

**Duration:** 0:58–1:15

---

## Scene 6 — The "Connect this screen" pairing prompt (Screen recording)

**Visual:** Screen capture of the actual pairing screen: the Daily View
logo, heading "Connect this screen," the instruction text, and the empty
code field.

**VO:**
> "You'll now see a screen that says 'Connect this screen,' with a box
> waiting for a code. Leave this open — we'll come back to it in a
> moment."

**On-screen text (matches real UI copy):**
> Connect this screen
> Ask your family member for the code shown in their Daily View
> dashboard, under Devices, then enter it below.

**Duration:** 1:15–1:32

---

## Scene 7 — Get the code from the dashboard (Screen recording, phone/laptop)

**Visual:** Screen capture switching to a phone or laptop: logging into
the Daily View dashboard, navigating to **Devices**, clicking **Add
device**.

**VO:**
> "Now pick up your own mobile phone or computer and log into your Daily View
> dashboard. Go to Devices and select Add device."

**On-screen text:** *Step 3 — On YOUR phone or computer: Dashboard → Devices → Add device*

**Duration:** 1:32–1:50

---

## Scene 8 — Name the screen and get the pairing code (Screen recording)

**Visual:** Screen capture of the "Add device" dialog — typing an
optional name like "Kitchen screen," choosing a device type, submitting.
Then the "Pair this device" dialog appears showing the 6-character code
and QR code.

**VO:**
> "Give the screen a name, so it's easy to recognise later — something
> like 'Mum's kitchen screen' works well. Then you'll see a short code,
> along with a QR code. This code stays valid for fifteen minutes."

**On-screen text (matches real UI copy):**
> Pair this device
> Enter this code on the Daily View screen, or scan the QR code with it.

**Duration:** 1:50–2:12

---

## Scene 9 — Enter the code on the screen (Screen recording, back to tablet)

**Visual:** Split-screen or quick cut back to the tablet: typing the code
into the "Connect this screen" box, tapping Connect.

**VO:**
> "Type that code into the box on the screen and select Connect."

**On-screen text:** *Step 4 — Enter the code and select Connect*

**Duration:** 2:12–2:25

---

## Scene 10 — It's live (Live-action + screen recording)

**Visual:** Screen recording shows the pairing screen replaced by the
live Daily View — today's date, time-of-day icon, event list, NEXT
highlighted. Cut to live-action: the carer propping the tablet up on a
stand or stable surface in the room where it will live, plugging the
charger in for good.

**VO:**
> "That's it — the screen now shows today's plan automatically, and it
> will keep itself up to date from here on. Find a stable spot for it —
> somewhere it'll stay plugged in and easy to glance at — and you're
> done."

**On-screen text:** *Connected — updates automatically*

**Duration:** 2:25–2:48

---

## Scene 11 — Closing reassurance (Live-action)

**Visual:** Wide, calm shot of the finished setup — the screen sitting in
its permanent spot.

**VO:**
> "If you ever need to make changes, everything is managed from your
> Daily View dashboard — the person using the screen never has to touch
> a device or account setting."

**On-screen text:** *Manage everything from your Daily View dashboard*
followed by end card: *Daily View — [SCREEN URL]*

**Duration:** 2:48–3:00

## Production notes

- **Copy accuracy:** All on-screen UI text above (`Connect this screen`,
  `Add device`, `Pair this device`, the instruction sentences) is pulled
  directly from the current dashboard and display code (
  `dashboard/index.html`, `dashboard/devices.js`, `display/index.html`),
  so screen recordings will match the video without needing to fake the
  UI.
- **Pacing for the audience:** Carers may be older adults themselves or
  unfamiliar with tech — favor slower cuts, hold each step's text a beat
  longer than usual, and avoid quick jump-cuts during the pairing steps.
- **Captions:** Burn in on-screen captions matching the VO — helps
  viewers who pause/rewind to follow along step by step, and covers
  silent autoplay contexts (e.g. embedded on the landing page).
- **No account/security detail on camera:** Don't show a real pairing
  code or QR code lingering on screen long enough to be paused and reused
  — use a test/demo account, and note in editing to blur or crop if a
  real one is ever captured.
